05 / Usage rules

Logo: place the approved bird-letter ARI + “by Karina” as one fixed lockup. Keep a simplified A symbol and plain wordmark for small digital icons. Do not auto-set the signature as ordinary editable text.

Hierarchy: one expressive display headline per page section; all transactional copy in the sans family. Avoid full uppercase paragraphs and excessive tracking. Use sentence case for product and collection names.

Localization: map Latin headings to Cormorant, Armenian headings to Noto Serif Armenian, Latin UI to DM Sans, Armenian UI to Noto Sans Armenian. Inspect Russian and French accents before launch. Retest line wrapping and button widths for each locale.

Accessibility: maintain at least 16 px body text in shopping flows, use comfortable line height (roughly 1.5–1.7), verify text contrast, and avoid placing fine ivory lettering over busy flower photography without an overlay.

/* Include the four font families loaded in the HTML head. */
:root {
  --ari-wine: #650d1c;
  --ari-wine-dark: #410714;
  --ari-ivory: #fff0e5;
  --ari-paper: #f8f2ec;
  --ari-rose: #b9858b;
  --ari-display: 'Cormorant Garamond', Georgia, serif;
  --ari-body: 'DM Sans', Arial, sans-serif;
  --ari-display-hy: 'Noto Serif Armenian', serif;
  --ari-body-hy: 'Noto Sans Armenian', sans-serif;
}
body { font-family: var(--ari-body); font-size: 16px; line-height: 1.6; }
h1, h2, h3, .editorial { font-family: var(--ari-display); font-weight: 400; }
h1 { font-size: clamp(38px, 6vw, 80px); line-height: 1.05; }
h2 { font-size: clamp(30px, 4vw, 52px); line-height: 1.12; }
.product-name { font: 400 26px/1.15 var(--ari-display); }
button, .price, .checkout, input { font-family: var(--ari-body); }
:lang(hy) h1, :lang(hy) h2, :lang(hy) h3 { font-family: var(--ari-display-hy); }
:lang(hy) { font-family: var(--ari-body-hy); }
